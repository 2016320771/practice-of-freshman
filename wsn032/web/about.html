Technique

用到的技术

  • HTML5 语义化结构

    使用 header / nav / main / section / figure / footer 组织内容，标题层级严格按 h1→h2→h3 递进，便于阅读也便于屏幕阅读器识别。

  • CSS3 变量与响应式

    配色、间距、字体统一用 CSS 自定义属性管理；字号用 clamp() 流体缩放，栅格用 grid 的 auto-fit 自动换行，手机端不出现横向滚动。

  • 相对路径互链

    主页在根目录，分页面在 web 目录，图片在 image 目录。跨目录引用统一用 ../ 回退，整包拷贝到任意磁盘位置都能正常打开。

  • 原生 JavaScript 交互

    移动端折叠菜单、照片灯箱（支持 Esc 关闭）、滚动淡入显现。不依赖任何 JS 框架与外部 CDN。

  • 无障碍细节

    导航项用 aria-current 标记当前页，按钮带 aria-expanded，图片全部提供 alt 文本，焦点可见；同时支持 prefers-reduced-motion 减少动画。

  • 打印样式

    单独设置打印媒体查询，去掉导航与首屏大图、改为白底黑字，方便直接打印成纸质作业。
